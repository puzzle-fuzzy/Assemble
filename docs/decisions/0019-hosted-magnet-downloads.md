# 决策 0019：服务器磁力下载与 HTTPS 回传

日期：2026-11-28。取代决策 0018 中本机执行 BT 和任务直连选择；保留其来源、文件安全与上传停止约束。

## 用户决定与原因

用户反馈 Mac 磁力解析一直失败，要求服务器解析并传回，不再设置直连。确认范围时选择“服务器解析、下载并通过 HTTPS 回传”。本机实测系统 TUN 路径关闭 BT 握手，因此只移走元数据不能解决实际下载；本次同时移走节点发现、元数据和分片交换，Mac 只连接第一方服务。

## 实现边界

`assemble-protocol::magnets` 定义普通已认证设备的私有预览、任务、控制、清单及固定分片接口；`assemble-client` 固定服务来源、禁止重定向、限制响应和取消时间。每次服务端请求重新认证并核对账户，不借用管理员 DHT API，也不写入全站观测库。原始磁力只短暂保留在服务器 Rust 内存；数据库只存去除外层参数的已校验元数据、所选标识和稳定请求键。

服务端复用下载规则和发布流程；独立安全 DHT/元数据读取器过滤非公网节点，BT 分片连接另用公网正向列表，关闭引擎自己的 DHT、局域网发现、入站、UPnP 和持久化。公共 Tracker 池继续筛选；HTTP(S) 与 UDP 引导都核对协议应答并固定公网地址。没有新增公网监听端口或系统路由设置。每任务上传限 256 KiB/秒，完成、暂停、退出即停；客户端每秒续租，断线超过 15 秒服务端暂停，服务器重启后也先暂停。

稳定创建键在本机发请求前持久保存。取消先落到服务器时也保存取消回执，迟到的创建只能补齐回执身份，不能恢复任务或预留。完成/取消意图持久化后才清理，实际删除成功才释放预留；重试不得跨越终态。

每任务按所选大小两份预留，与云盘及设备上传共享全站预算；单账户活跃所选总量另受 `ASSEMBLE_DRIVE_QUOTA_BYTES` 限制（默认 2 GiB）。每账户最多 8 个活跃任务，全站 128 个、4 个 BT 执行、2 个元数据解析；元数据总计 64 MiB，回执最多 10,000 条。缓存租期 24 小时，运行心跳延长；过期取消清理，已清空终态回执再保留 30 天。实际磁盘余量仍须满足通用下载边界。

BT 完成后停止会话并校验发布，再按 4 MiB 分片和整文件 SHA-256 回传。Mac 校验长度、分片与整文件，缓存通过校验才能复用，最后无覆盖发布并确认服务器释放缓存。进度区分“服务器下载”和“正在保存到本机”。旧记录与缓存保留，继续时转为服务端任务；旧网络模式只供兼容读取，不再提供界面或助手参数，客户端引擎禁止回退本机 BT。

## 验证边界

真实回环 BT 与 HTTP 集成覆盖元数据、文件选择、暂停、租约过期、服务重启、账户隔离、取消时序、清理，以及 Mac 队列坏分片拒绝、重启复用缓存和最终摘要。全仓验证、真实镜像启动、线上资源与 Mac 安装分别记录；回环通过不能证明特定公网资源有可达节点。本轮按用户要求先验 Mac，不扩展 Windows 专项工作。

## 真实运行发现：解析节点必须传给下载

首轮线上解析指定公开样本成功，但下载停在 0 B。原实现只让下载等待短时 DHT 结果，丢掉了解析阶段已经握手成功的节点；固定种子预置到下载的旧测试没有覆盖这条衔接。现在按信息哈希暂存最多 128 组、每组 64 个已过滤节点，十分钟过期，只留 Rust 内存，已握手节点优先交给下载。后续冷启动实测又发现：已经持久保存元数据的任务不应再次依赖元数据提供者。恢复改为直接校验已有元数据与 BT 缓存，再寻找数据节点。

回归种子仅用于元数据握手，下载阶段通过同一发现与节点衔接路径开始；销毁服务后再恢复，测试不提供任何元数据节点，只在初始发现窗口结束后延迟发送节点事件，验证冷启动能持续发现并完成 HTTPS 摘要校验。回环地址的放行只在显式测试特征下编译，正式镜像的公网边界保持强制。运行诊断只记录节点计数与字节数，不记录来源或地址；速度按真实接收字节计算，重新校验已有缓存不计入网速。

安全 DHT 的新节点通过进程内 UDP Tracker 接入引擎：每个运行任务使用随机回环端口、随机连接标识和绑定的信息哈希，只返回当前任务的已过滤节点，消息和列表都有上限。DHT 查询每 15 秒触发，接收持续开放；内部 Tracker 按 10 秒提供更新，外部 Tracker 仍遵循自身间隔。回环端口仅属于可信适配器，不来自用户输入，不映射到容器外。退出先停 BT 会话，再取消并等待适配器释放端口；普通来源仍拒绝私网，BT 数据仍受公网正向列表约束。

线上再次粘贴同一链接时，外部元数据节点可能已经离线，即使本人任务仍保存着已验证元数据也会重新超时。预览现在先复用同账户、同信息哈希、未过期活跃任务的元数据，重新核对信息哈希、路径和公开标记；不读取其他账户、已释放或过期任务。缓存命中无需初始化网络，未命中仍执行正常的限时解析。这只解决元数据重复获取，不代表资源的数据节点充足。
