# 决策 0016：助手复用桌面端本机下载队列

- 状态：已采用；源码与定向验证完成，正式发布及 Windows/macOS 的助手真人下载待验收
- 日期：2026-11-27

## 原因

用户要求同时推进 C1，让助手可以解析视频地址并在本机下载。下载本身已由桌面应用承担，不能让 MCP 进程另建队列或并发改写同一个任务文件。

## 决定

桌面应用是下载任务的唯一执行者。MCP 复用浏览器扩展已有的本机回环通道和系统钥匙串中的发现信息，先完成挑战应答，再发出受保护请求。端口、令牌、来源地址中的认证信息与原始诊断均不出现在工具结果或界面状态中。桌面没有运行时明确返回不可用，不替用户启动。

首批提供三个具名工具：`assemble_download_preview`、`assemble_download_start`、`assemble_download_status`。先预览标题、时长与清晰度，随后使用解析标识与选择的清晰度开始；状态只返回安全投影，完成后给出文件名。本期不向助手返回完整本机路径，也不接受路径输入。保存目录始终由桌面设置和系统目录选择器决定。

助手与浏览器入口共用下载安全规则、并发和容量限制、网络来源校验与 FFmpeg 流程。既有浏览器扩展消息保持兼容；助手任务明确记录来源标记。状态与取消仍经认证的本机通道，不新增服务端远程下载 API。

“允许助手在这台电脑下载”默认开启，并在本机设置中可关闭；先确认设置持久化成功，再更新运行中的开关。关闭后助手请求返回固定错误码，既有浏览器和手动入口保持原有用途。任务行展示“由助手发起”，不包含助手会话、模型或其他身份资料。

## 验证边界

自动化验证覆盖挑战和认证、预览与开始两步、幂等、关闭开关、桌面未运行、失败任务和返回值中没有凭据或路径；界面覆盖两种语言、开关失败时不伪造成功与助手来源标记。

这些结果不代表真人已经通过对话发起下载或视频已在两种系统上播放。使用与最终发布记录见[网络下载手册](../runbooks/network-downloads.md)。

2026-11-27 磁力下载扩展：预览返回实际文件清单，开始必须带文件标识；新增 `assemble_download_pause`、`assemble_download_resume`、`assemble_download_cancel`。用户已确认下载期间限速上传、完成即停，界面和工具说明同步明确。恢复与凭据设计见[决策 0018](0018-magnet-local-downloads.md)。
