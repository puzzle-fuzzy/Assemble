# 决策 0007：管理端与桌面端共享语言和外观

- 状态：已采用
- 日期：2026-11-25

## 原因与范围

用户要求管理后台与桌面应用内页面支持国际化、日夜主题，并确认首批为简体中文与英语。浏览器的登录、注册、找回密码等身份页，以及系统托盘、系统通知暂不纳入。沿用当前布局、shadcn 组件与配色，切换外观不重新设计页面。

2026-11-26 用户追加身份页视觉对齐：这些 Rust 页面已复用同一 shadcn 样式、字体与系统深色回退，但文案仍为中文，不新增语言菜单、手动主题偏好或身份表单脚本。样式生成与安全边界见[身份页界面说明](../runbooks/browser-identity-ui.md)。

## 语言

默认简体中文；用户在左下角账户菜单的“语言”中切换 English 或简体中文。管理端未登录、无权限和加载失败时，以及桌面发送面板，仍提供语言与外观入口。

`packages/display` 提供同一个 i18next / react-i18next 实例；两端分别维护系统文案字典，共享控件维护独立字典。资源随应用打包，不调用翻译服务。菜单、表单、空状态、错误、提示、无障碍标签、页面标题及日期数字格式均随选择更新。新文案同时维护中英两份；句子整体插值、数量按语言处理，不能拼接固定语序。

用户输入的姓名、邮箱、设备名、文件名、日程标题和备注原样展示。切换语言不改变日期代表的时刻或业务时区，也不改变服务端错误码；Rust 诊断内容仍不直接回显给用户。

2026-11-27 用户要求管理端和桌面端的日期、时间选择使用 shadcn 官方组件，避免系统原生选择面板。影视的上映、观看日期，以及桌面日程和提醒的开始、到期、结束时间，统一使用 `packages/ui` 的 Date Picker 组合：通过官方 CLI 添加 Calendar，并复用 Popover、InputGroup 与 Select。日期可手动输入或在日历选择，时刻通过小时、分钟菜单选择，清除不提交表单；中英标签、日历语言与日夜主题跟随两端已有偏好。影视仍传 `YYYY-MM-DD`，日程仍先按本机时区收集 `YYYY-MM-DDTHH:mm` 再经原有逻辑转 UTC；切换语言、主题或选择面板不改变业务时区，也不修改服务端协议。

同日用户继续要求两端其余下拉框也统一为官方 shadcn Select，其余功能不变。日程的重复、提醒提前量，以及影视编辑和导入的类型、状态、资料源，均复用已安装的同一个 Select 实现；旧 `select` 入口只做转发，不保留原生菜单。选项、默认值、禁用条件、保存和搜索时机均保留，包括助手设置的非预设提前量；“到点时提醒”的非空选项值仅用于界面适配，保存仍为原来的 `null`，不改变协议和数据。

随后用户要求继续排查原生控件和自写基础组件，能由官方 shadcn 组件承担的展示统一替换，其余功能不改。两端的独立错误提示使用 Alert，字段错误使用 FieldError，下载与影视导入预览使用完整 Card 组合，纯文字空状态使用 Empty，发送文件条目使用通过官方 CLI 添加的 Item，设置分隔线使用 Separator；复用原有文案、状态、事件与读屏角色。系统通知已有的 polite 状态公告不改成强制中断，登录超时仍由 Sonner 显示。DatePicker、DataTable、LoadingState、页面面包屑及影视图片读取等是官方基础控件之上的业务组合，保留其原有功能；官方组件源码内部的原生元素和登出表单的隐藏 CSRF 字段不属于需要移除的可见原生控件。

现有 Rust `Notice` 仍提供面向用户的中文消息。应用内按已知完整消息和明确的文件名模板映射到本地字典，不能对任意消息做字符串替换或误译文件名；未知消息在两种语言下都使用安全通用提示，避免把潜在诊断当成用户文案。这个展示适配不改变 Rust 快照、原生托盘或系统通知。已显示的登录超时 toast 与表单错误也随语言更新，不重复操作或清空用户草稿。

## 外观与存储

使用 shadcn DropdownMenu 的语言、外观子菜单及单选状态，提供浅色、深色、跟随系统三个明确选项。默认跟随系统，持续监听系统颜色变化。手动选择一直有效，即使系统后来恰好切换到相同颜色也不能丢弃覆盖值。Sonner 提示与原生表单控件跟随已解析的主题。

只将外观偏好保存到当前浏览器/WebView 的 `localStorage`（`assemble.display.v1`），不进入服务端账户、Rust 状态或凭据存储。桌面同源窗口通过存储事件同步；管理网站和桌面各记各的选择，不承诺跨设备同步。切回跟随系统会删除主题覆盖值；存储损坏或不可用时可正常启动并在当前窗口切换。

两端使用同一个 Vite 插件，在样式绘制前加载同源的同步外部脚本，恢复主题并设置 `<html lang>`、`color-scheme`。管理端保持 `script-src 'self'`，不为防闪烁放开内联脚本或修改 nginx。共享 CSS 在脚本尚未执行时也提供系统深色回退。

## 验证边界

自动化验证覆盖主题覆盖/系统变化、偏好恢复、存储不可用与跨窗口事件、句子插值与数量、中英文页面交互和共享菜单。真实浏览器与 Windows 桌面验收单独记录；自动化通过不代表已经完成 macOS 真机或跨设备验收。
