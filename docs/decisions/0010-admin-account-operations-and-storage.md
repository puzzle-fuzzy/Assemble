# 0010：管理端账户操作与存储监控

- 日期：2026-11-26。
- 状态：源码已实现；正式部署与真人验收另行执行。
- 背景：用户选定工作包 A1、C2，明确不处理 iOS 真机及推送。账户停用已有 CLI，网页缺少入口；磁盘与内容预算缺少统一观测。

## 决定

管理端用户详情增加停用、恢复操作，使用共享 AlertDialog，默认焦点在取消。正常浏览仍为 GET，两个专用 POST 子路径返回更新后的 `AdminUser`，新增 `suspended` 布尔字段。当前管理员不可停用自己；不提供删除账户或公开提权。

账户操作复用验证邮箱的管理员 HttpOnly 会话，同源检查之外逐次校验唯一 Origin 与会话 CSRF。公共写入防伪校验与影视写入共用 `auth::verify_browser_write`；各业务提取器保留自己的权限边界，不扩大设备令牌权限。取得写锁后重新校验操作者，状态与操作者/目标审计共用事务；重复操作不追加审计，失败回滚。

停用立即撤销网页会话，后续登录及设备请求被拒；网页操作通过服务端内部事件终止已建立设备流，不增加设备协议事件类型。订阅后再次核对设备有效性，避免认证与订阅之间漏掉停用通知。CLI 在独立进程执行，依赖现有心跳复查结束长连接。恢复保留原有设备凭据，网页须重新登录；账户、文件与设备数据均保留。

`storage::report` 提供文件内容总量、预算、数据库文件长度、数据卷余量、预警状态和用量前十账户，供管理概览与 `check-config` 共用。内容总量遵循 `SUM(blobs.size)`，数据库包含 SQLite 主文件、WAL、SHM，无法测量时明确为 null；不暴露服务器路径、内容摘要或凭据。

账户用量只按云盘和待接收发送的引用，每账户内部去重，跨账户不能相加代替全站总量。排名保留停用账户，按用量倒序、标识正序稳定截取十项。内容达到配置百分比或磁盘余量低于 2 GiB 时预警；维护日志按单调时钟限为每进程每小时一次，测量不可用也会提示。无需迁移，不修改既有脚本，不自动删除数据。

## 验证边界

临时数据库与真实 HTTP 测试覆盖权限、CSRF、本人保护、幂等、审计回滚、已有事件流关闭、设备请求拒绝、恢复与统计口径。网页测试覆盖确认取消、安全焦点、同步更新、迟到响应取消、中英文、预警及未知值。Windows 本地隔离启动和浏览器核对属于运行证据；正式账户的实际操作与服务器容量对照仍由发布后的真人验收完成。
