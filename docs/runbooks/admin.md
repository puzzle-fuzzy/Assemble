# 管理端

管理页面是同源的 `/admin/`，正式入口为 <https://as.yxswy.com/admin/>。本次提供只读概览、注册用户、设备和成功登录记录；暂不提供定时邮件、RSS、账号删除或封禁。

管理端只作为网页在浏览器中使用，不需要安装桌面程序，也不嵌入 Assemble 桌面客户端。用户于 2026-11-25 再次明确此边界：共享 `packages/ui` 仅表示复用基础组件、主题和字体，不能理解为共用桌面应用壳。下方 `127.0.0.1:1421` 是开发用网页地址；正式使用方式是浏览器访问服务器发布的 `/admin/`。

## 初始化超级管理员

在服务器受保护的 `/opt/assemble/.env` 加入 `ASSEMBLE_SUPER_ADMIN_EMAIL=<本人控制的邮箱>`，权限保持 600，不提交真实配置。本人从公开注册页注册并完成邮件验证，或使用 GitHub 后补绑、验证指定邮箱；然后登录管理端。只有已经验证的指定邮箱可获权限，其他注册用户始终是普通账户。公开注册无需邀请码。

环境配置在启动时以及成功登录时生效。已验证账户也可以由服务器操作者执行：

```sh
cd /opt/assemble
docker compose exec assemble assemble-server grant-super-admin <已验证邮箱>
```

授权与审计在同一事务完成，可重复运行，不提供公开提权 API。密码由本人在浏览器设置或输入，不能放进命令参数、聊天、日志或文档。后续取消环境变量不会撤销已经授予的角色。

允许多个超级管理员并列。2026-11-25 用户指定两个邮箱：已验证的账户已通过上述 CLI 获得权限并留下审计，另一个尚未注册的邮箱由受保护 bootstrap 配置保留，验证后自动授权。真实邮箱不写入仓库文档；授权不改变原账户或 GitHub 绑定。

## 页面与数据口径

- 概览显示用户数、已登记设备数、在线设备数和北京时间当天的注册数。在线来自现有事件流 Presence，不把近期登录当成在线。
- 用户列表可按标识、显示名、已验证邮箱查询；详情显示该用户设备和最近 100 次成功登录。
- 设备页可按所属用户、设备名称与平台查询，显示登记时间、最后在线时间和当前状态。
- 登录页记录邮箱或 GitHub 成功建立网页会话的时间；历史数据缺失时显示“未记录”，不从创建时间推断。
- 列表按时间及标识稳定倒序分页；日期由服务端提供 UTC 时间，界面统一按北京时间显示，与“今日注册”的统计口径一致。
- 没有登录时提供系统浏览器的网页登录入口；普通账户显示无管理权限。权限由服务端判断，前端隐藏菜单不能替代鉴权。
- 管理登录页明确显示“登录管理控制台”，登录成功后直接返回 `/admin/`；从此入口找回密码后，重新登录链接也回到管理端。退出管理控制台后返回管理登录页，全程留在网页中，不要求打开或安装桌面程序。

## 开发与发布

```sh
bun install --frozen-lockfile
bun run admin:dev       # 127.0.0.1:1421/admin/，代理到 127.0.0.1:8787
bun run admin:build     # apps/admin/dist
bun run build:frontend  # 桌面和管理前端一起构建
bun run verify
```

直接在仓库根目录启动服务端时，默认读取 `apps/admin/dist`；可通过 `ASSEMBLE_ADMIN_ASSETS_DIR` 指向构建目录。Docker 镜像在 Bun 阶段构建管理端，运行时读取 `/usr/share/assemble/admin`，不需要另外部署站点或改变共享 nginx。

本机查看服务端实际托管的网页时，先执行 `bun run admin:build`，再执行 `bun run server:dev`，浏览器访问 `http://127.0.0.1:8787/admin/`。这与开发热更新用的 1421 地址用途不同；两者都只提供网页。正式使用时仅需浏览器访问已部署服务，不需要在管理员电脑上启动本地服务、安装 Bun 或安装 Assemble 桌面端。

管理端通过原生同源 POST 表单提交退出，并只允许返回固定 `/admin/` 的登录入口。服务端确认撤销会话后才清理浏览器 Cookie；撤销失败时保留会话并提示重试。其他网页账户退出页保留重新登录的网页链接。

管理端与桌面端通过 `@assemble/ui` 引用 `packages/ui`。添加基础组件在该包目录使用 `bunx --bun shadcn@latest add <组件>`，保留既有主题；两个应用不复制独立实现。

## 核对清单

自动化覆盖管理员授予、同源读取、普通账户/未验证账户/设备令牌拒绝、查询分页、登录记录和静态目录边界。发布后另核对 `/admin/` 与带哈希资源可读取、未登录接口返回 401；本人完成验证后再核对真实管理员登录与设备数据。正式环境不创建临时测试账号，不恢复已经清空的旧账号。
