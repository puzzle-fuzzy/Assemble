# 管理端

## 操作日志

2026-11-27 按用户要求新增源码入口“操作日志”（`/admin/#activity`）。记录远程连接的请求、批准和结束，云盘文件的上传、改名和删除，影视条目/合集的维护，以及文件发送和接收等终态。每行展示操作人、设备、北京时间、动作和对象；类型、关键词、起止日期可组合筛选，分页与刷新沿用共享 shadcn 表格。日志手动刷新，不影响既有业务流程。

文件、影视条目和合集点击后按唯一标识打开现有详情，不依赖列表当前页；远控与传输打开只读详情和最近一百条相关记录。已删除对象保留元数据与记录；历史日志没有保存的名称、设备或快照显示“未记录”，不会补造。系统自动超时、设备撤销及服务重启造成的远控中断有结束记录，同一阶段重复批准/结束只记一次。

接口为 `GET /v1/admin/activity`（`q/category/from/through/page/pageSize`）、`GET /v1/admin/activity/targets/{kind}/{id}` 及深链接所需的 `GET /v1/admin/drive/files/{id}`。类型为 `files/transfers/media/remote`，省略或 `all` 表示全部；日期为 `YYYY-MM-DD`，按北京时间自然日包含首尾两日。每次读取均校验已验证邮箱、超级管理员和同源；设备令牌不可用，响应不缓存。记录仅包含安全业务元数据，不包含密码、令牌、Cookie、防伪值、远控握手/验证码/画面/输入/剪贴板、服务器或本机路径、文件正文、影视备注和磁力。

新增迁移 `0015_activity_log.sql` 扩展已有 `audit_log` 并维护只读对象元数据；不改变原始业务表结构或删除既有审计。升级前按部署手册备份完整 SQLite 数据库与 `blobs/`，启动时自动迁移。旧审计只分类、解析原有标识，不能恢复之前未记录的内容。远控当前阶段以数据库保留的安全元数据为准，进程启动时将旧进程遗留的未结束会话标记为中断。本节描述源码能力，正式部署需另行核验。

管理后台支持简体中文与英语，以及浅色、深色、跟随系统主题。在左下角管理员账户菜单中选择“语言”或“外观”；未登录、无权限等页面右上角仍有同一入口。偏好在当前浏览器中保存，刷新恢复；不与其他设备或桌面应用同步。登录、注册、找回密码的服务端网页尚未纳入国际化，详见[决策 0007](../decisions/0007-language-and-appearance.md)。

管理页面是同源的 `/admin/`，正式入口为 <https://as.yxswy.com/admin/>。当前源码支持概览、注册用户、设备、成功登录记录，以及用户详情中的停用、恢复账户；本轮运营功能尚未部署。2026-11-25 用户另确认共享影视维护、合集和统计，当晚已随 `b984a100b01f` 正式部署，见下方影视边界与[影视手册](media.md)。暂不提供定时邮件、RSS 或账号删除。

管理端只作为网页在浏览器中使用，不需要安装桌面程序，也不嵌入 Assemble 桌面客户端。用户于 2026-11-25 再次明确此边界：共享 `packages/ui` 仅表示复用基础组件、主题和字体，不能理解为共用桌面应用壳。下方 `127.0.0.1:1421` 是开发用网页地址；正式使用方式是浏览器访问服务器发布的 `/admin/`。

## 初始化超级管理员

在服务器受保护的 `/opt/assemble/.env` 加入 `ASSEMBLE_SUPER_ADMIN_EMAIL=<本人控制的邮箱>`，权限保持 600，不提交真实配置。本人从公开注册页注册并完成邮件验证，或使用 GitHub 后补绑、验证指定邮箱；然后登录管理端。只有已经验证的指定邮箱可获权限，其他注册用户始终是普通账户。公开注册无需邀请码。

环境配置在启动时以及成功登录时生效。已验证账户也可以由服务器操作者执行：

```sh
cd /opt/assemble
docker compose exec assemble assemble-server grant-super-admin <已验证邮箱>
```

授权与审计在同一事务完成，可重复运行，不提供公开提权 API。密码由本人在浏览器设置或输入，不能放进命令参数、聊天、日志或文档。后续取消环境变量不会撤销已经授予的角色。

允许多个超级管理员并列。2026-11-25 用户指定两个邮箱：已验证的账户已通过上述 CLI 获得权限并留下审计，另一个尚未注册的邮箱由受保护 bootstrap 配置保留，验证后自动授权。真实邮箱不写入仓库文档；授权不改变原账户或 GitHub 绑定。

## 页面与数据口径

- 概览显示用户数、已登记设备数、在线设备数和北京时间当天的注册数。在线来自现有事件流 Presence，不把近期登录当成在线。
- 用户列表可按标识、显示名、已验证邮箱查询；详情显示该用户设备和最近 100 次成功登录。
- 管理列表按 Jarvis 参考图统一为外置紧凑工具栏、浅灰表头、平铺数据行、文字操作列及右下分页；显示列可隐藏非关键列。详情一律使用弹窗，关闭后保留搜索和当前页，并把焦点交回原入口。影视合集同样采用表格和详情弹窗，统计分组使用表格展示。
- 2026-11-26 用户反馈长列表滚动会带走左侧菜单。管理壳固定占用动态视口高度，左侧菜单、底部账户菜单和 48px 页头始终留在视口内，仅右侧内容区域独立滚动；窄屏沿用页头功能菜单。共享表格为隐藏的辅助文字提供就近定位范围，避免分页按钮的绝对定位文本越过滚动容器并撑高整页；内容滚动到边缘也不向外层页面传递滚动。
- 2026-11-26 用户进一步要求每个表格必须有左侧拖拽柄和多选框两列，可以禁用但不能省略。管理、桌面与弹窗内的表格统一使用共享 DataTable；多选仅作用于当前页，翻页或更换结果集清除选择。服务端固定排序的名单禁用拖拽，统计汇总同时禁用多选；禁用控件仍显示。影视合集编辑中的成员可拖拽或用 Alt 加上下方向键调整，保留上移/下移按钮，保存合集时提交实际成员顺序。
- 2026-11-26 用户要求已有用户展示页的功能，一律在对应管理表格的右上工具栏提供入口。影视共享片库的“查看影视站”打开 `/movies/`，影视合集的“查看合集页”打开 `/movies/collections`；均使用新标签页，保留管理端的搜索、分页和编辑状态。入口同时维护中英文名称。
- 设备页可按所属用户、设备名称与平台查询，显示登记时间、最后在线时间和当前状态。
- 管理端分页表格默认每页 20 条，涵盖用户、设备、登录记录、云盘、DHT、影视和合集；仍可在分页条调整条数。共享组件的桌面与 ToC 默认条数不变，未分页的完整详情名单仍完整展示。
- 2026-11-27 用户要求层级跳转集中在面包屑，移除与其重复的返回按钮。管理端与桌面端共用 `PageBreadcrumbs`：父级是可键盘访问的链接，当前位置使用 `aria-current`，跳转后聚焦新当前位置；长片名完整保留并可横向阅读。桌面影视详情显示“影视 → 片名”，点击“影视”返回原搜索、页码与每页条数，不重新请求列表；切换账户立即清除旧片名。管理端现有详情弹窗沿用关闭和原列表焦点，弹窗不伪装成外层页面层级；外站入口、分页、表单取消和图片轮播仍保留各自语义。
- 云盘页查看所有账户的云盘文件，支持文件名、用户姓名、标识及已验证邮箱搜索与稳定分页；显示文件名、所属用户、邮箱、大小、类型和存入时间，详情以弹窗展示。2026-11-27 用户明确授权管理员下载查看文件，行内“详情”旁增加“下载”，由浏览器原生保存附件。停用账户的文件仍可由管理员查看和下载；不增加跨账户删除、改名或服务器文件系统浏览能力。
- 登录页记录邮箱或 GitHub 成功建立网页会话的时间；历史数据缺失时显示“未记录”，不从创建时间推断。
- 列表按时间及标识稳定倒序分页；日期由服务端提供 UTC 时间，界面统一按北京时间显示，与“今日注册”的统计口径一致。
- 没有登录时提供系统浏览器的网页登录入口；普通账户显示无管理权限。权限由服务端判断，前端隐藏菜单不能替代鉴权。
- 管理登录页明确显示“登录管理控制台”，登录成功后直接返回 `/admin/`；从此入口找回密码后，重新登录链接也回到管理端。退出管理控制台后返回管理登录页，全程留在网页中，不要求打开或安装桌面程序。

## 停用、恢复与存储监控

云盘行内增加“预览”，与桌面端复用弹窗内容和中英系统文案；关闭后恢复列表焦点、搜索与分页。管理员预览描述 `/v1/admin/drive/files/{id}/preview` 与媒体 `/preview/content` 都逐次检查已验证邮箱、管理员与同源会话；只允许经过内容校验的图片、音视频内联，文本按原文显示，不执行 HTML/SVG，不嵌入 Office/PDF。下载入口继续保留。格式、资源上限和验收见[云盘预览手册](file-preview.md)。

N2 文件夹源码增加“浏览文件夹”和行内所属用户入口；可选择包括空云盘在内的账户，再通过顶部面包屑进入和返回目录。全站平铺列表保留，目录列表默认每页 20 条，预览、详情和下载复用现有权限；不显示创建、上传、改名、移动或删除动作。`GET /v1/admin/drive/tree?accountId=&parentId=root&q=&page=1&pageSize=20` 每次校验同源、邮箱验证和管理员，设备令牌不能访问。N2 尚未部署，实际契约与验收见[文件夹手册](drive-folders.md)。

2026-11-26 用户要求独立的管理云盘界面，查看所有存储文件及服务器剩余可存储空间。`GET /v1/admin/drive/files?q=&page=1&pageSize=20` 返回 `AdminPage<AdminDriveFile>`；文件字段为 `id/accountId/accountDisplayName/accountEmail/name/size/mimeType/createdAt`，邮箱只返回已验证值，类型未知时为 null。`GET /v1/admin/storage` 单独返回与概览一致的 `AdminStorage`。两者复用逐次管理员、已验证邮箱和同源检查，设备令牌不能访问，响应禁止缓存，不返回内容摘要、凭据或落盘路径。

`GET /v1/admin/drive/files/{id}/content` 是 2026-11-27 新增的管理员文件内容入口：没有凭据的同源下载链接复用 HttpOnly 网页会话，每次校验管理员权限、已验证邮箱和同源来源；未登录或失效会话返回 401，已登录但权限或来源不符返回 403，文件不存在返回 404。浏览器下载导航可仅带 `Sec-Fetch-Site: same-origin`，跨站、同站其他子域以及缺少来源证明的请求均拒绝。响应沿用原云盘附件的 `Content-Disposition`、UTF-8 文件名和 Range/条件读取，并保留 `no-store`、`nosniff`、`Cross-Origin-Resource-Policy: same-origin`。普通设备下载入口仍仅可读取本账户，不新增前端可读凭据、签名 URL 或管理员写入权限。

云盘页将服务器磁盘可用量、文件内容去重用量与全站预算、数据库（含图片与日志）分开显示。“当前可用文件空间”取 `max(0, budgetBytes - contentBytes)` 和 `diskAvailableBytes` 的较小值；无法测量磁盘时显示“暂不可用”，不编造零值。它是全站当前容量估计，实际上传继续受 Rust 端全站预算与各账户云盘配额限制。列表仅列出持久云盘文件，不把设备中转记录或数据库图片伪装成云盘文件。

用户于 2026-11-26 选定 A1、C2，明确不处理 iOS 与推送。用户详情弹窗显示账户状态及“停用账户”或“恢复账户”；两种操作均先确认，默认焦点在取消。当前管理员不能停用自己。成功后同步更新详情和当前名单，不离开列表、不清空搜索条件。

停用保留账户、设备和文件数据，但立即撤销该账户全部网页会话，拒绝后续登录及设备请求；网页操作会通知已有事件流结束，在线计数不再包含该账户。恢复后设备原凭据仍可使用，网页必须重新登录。独立 CLI 无法通知另一进程的内存事件总线，已有流在下一次心跳检查时结束；CLI 仍可在网页不可用时使用。

新增 `POST /v1/admin/users/{id}/suspend` 与 `/resume`，无请求体，返回更新后的 `AdminUser`；列表、详情和返回值均增加 `suspended: boolean`。逐次要求已验证邮箱的管理员网页会话、恰好一个本站 `Origin`、匹配会话的 `X-CSRF-Token`，不接受设备令牌；读接口仍保留同源检查。不能停用自己返回 400，未登录 401，权限或 CSRF 拒绝 403，不存在的目标 404。原 `POST /v1/admin/users/{id}` 继续返回 405。

权限在写事务内再次核验；状态与审计共同提交，审计记录操作者和目标账户，写入失败则回滚。重复停用、恢复都成功，但只有真实状态变化才追加审计。不提供删除账户或自提权入口，不向浏览器发送密码、会话摘要、设备令牌或授权码；会话响应里的 CSRF 防伪值继续只服务于本站已授权写操作。

概览新增存储卡片，`GET /v1/admin/overview` 增加 `storage`：`contentBytes`、`budgetBytes`、`databaseBytes`、`diskAvailableBytes`、`warningPercent`、`budgetWarning`、`diskWarning`、`topAccounts`。前十账户包含 `id/displayName/email/avatarUrl/contentBytes`，邮箱只对已验证账户有值。

- 文件内容总量是 `SUM(blobs.size)`，与全站预算相同，含清理前的无引用内容；物理文件系统的分配块大小不在此口径。
- 数据库计量包括 SQLite 主文件、WAL 和 SHM，影视图片 BLOB 在其中；该值单列，不计入文件内容预算。
- 磁盘余量来自数据目录所在卷，反映同卷所有程序共同使用后的可用空间。数据库或磁盘测量失败返回 `null`，界面显示“暂不可用”，自检标为数据不完整。
- 前十账户统计云盘与待接收发送引用的内容，每账户按摘要去重；跨账户共享内容不能相加当作全站总量。停用不删除数据，所以账户仍可能在排名中。用量相同按账户标识稳定排序，不返回服务器路径、摘要或文件内容。
- 内容达到预算的 `ASSEMBLE_STORAGE_WARN_PERCENT`（默认 80，允许 1～100 的整数）或可用空间低于 2 GiB 时，通知中心记录预警，存储区域显示当前异常的紧凑提示。维护任务也记录容量或测量异常，每进程按单调时钟一小时最多一条；不发送邮件，不自动删除文件。

阈值配置、自检与扩盘核对见[部署手册](deploy.md)。这些运营功能不需要新迁移，复用已有 `suspended_at` 和审计表；正式部署后的真人停用、恢复及磁盘数字核对仍需单独验收。

2026-11-26 本地验证：全仓 `bun run verify` 通过，用时 77.8 秒，287 项 TypeScript/工具测试、521 项 Rust 测试通过；1 项 macOS 限定测试跳过，2 项既有 Rust 测试保持忽略。Windows 隔离服务通过浏览器完成测试管理员登录、取消/停用/恢复、安全焦点、名单同步及中英文存储概览；两份文件保留，物理内容与统计同为 81920 字节，状态变更仅两条审计。测试服务已停止，未连接正式数据库。Windows 共用编译目录时不要并行执行多轮完整检查：重新链接与运行测试程序可能发生文件占用，本轮最终以顺序执行的完整验证为准。

## 系统通知

管理端与桌面端顶部右侧新增同样的铃铛和居中通知弹窗，中英及主题共用；通知不会自动弹开，也没有刷新按钮，后台自动同步和失败重试。管理端记录存储预算、磁盘余量、测量异常和恢复，各管理员单独记已读。存储页内仍显示当前异常，概览顶部不再重复放大横幅。已读只表示看过，不能清除实际问题；数值变化不重复变为未读，恢复或严重程度变化产生新版本。

维护每分钟观察，网页在可见时每三十秒同步及重新聚焦时刷新；服务重启仍保留通知。`GET /v1/admin/notifications` 返回 `{items,available}`，`POST /v1/admin/notifications/read` 接受 `{items:[{id,revision}]}` 并返回新名单；最多一百项，要求既有管理员、同源与 CSRF，写事务复核权限，不接受设备令牌。读取、更新失败只给出可恢复的本地化提示，不显示服务器诊断。

新增迁移为 `0007_system_notifications.sql`；升级前按既有手册备份数据库，不能改已应用脚本。桌面通知属于本机及对应账户，不提供桌面管理能力；不更改日程通知、iOS 或远程推送，详见[决策 0012](../decisions/0012-system-notifications.md)。

## 影视维护边界

本轮源码新增“影视片库”：管理员维护共享条目，支持想看、在看、已看三状态、筛选与编辑、来源搜索/资料核对/导入、真实阶段任务、图集同步/选封面、合集成员与顺序以及共享统计。合集中不能加入私人条目，统计不能读取私人库。共享观后感可公开，共享备注仅管理员可读，磁力只向已登录账户返回；普通账户与匿名能读取的共享接口仍由服务端执行字段投影。

共享维护只在网页 `/v1/admin/media` 执行，逐次校验已验证邮箱、超级管理员、Origin 与 CSRF，不接受设备令牌。桌面端只维护本人私人片库；即使账户同时有管理员角色，也不在桌面提供共享管理能力。ToC `/movies/` 是同源只读展示，公开共享内容，登录后只读本人私人库和共享磁力，没有维护入口。

影视业务组合、中英字典由 `packages/media` 复用，基础组件、字体、主题仍共用 `packages/ui`，不复制管理专用控件或桌面应用壳。TMDB 凭据只由 Rust 读取 `ASSEMBLE_TMDB_TOKEN` 或 `_FILE`，管理表单不提供密钥编辑。来源配置、0005 迁移、包含 SQLite 图片 BLOB 的备份与验收步骤见[影视手册](media.md)和[决策 0008](../decisions/0008-media-libraries-and-viewer.md)。

影视部分 2026-11-25 已正式部署，正式容器里取 TMDB 与豆瓣的资料是通的；2026-11-26 按用户授权导入 Jarvis 线上 145 条影视、16 个合集、7 条缓存和全部封面及旧影视归档，已核对完整性与读取权限。管理维护、跨设备的真人操作仍需本人验收，见[影视手册](media.md)。下方既往管理端的验收记录是当时的状态。

2026-11-26 的 Windows CI 捕获了管理端懒加载测试的就绪判断竞态：加载指示前 200ms 没有文字，仅凭文字连续稳定会提前结束等待。测试辅助函数现在同时等待 `aria-busy` 结束和文字稳定，并保留五秒失败期限；新增回归覆盖空白但仍在加载的页面。运行时加载样式不变。

## 开发与发布

2026-11-27 用户反馈 DHT 翻页后刷新会回到第一页，并要求状态保存在地址栏。管理端的用户、设备、云盘、登录记录、DHT、影视片库和合集已统一按网址恢复分页；例如 `/admin/#dht?page=3&pageSize=50&status=all&source=sample&q=example`。页码、每页条数、已提交的搜索及列筛选进入哈希参数，刷新首次请求就使用这些值；浏览器前进、后退同步表格与搜索框，不写 localStorage。搜索和筛选变化回到第一页，每页条数变化也回到第一页；服务端返回的总数不足时，替换当前地址退到有效末页，避免后退循环。

影视页用 `tab=collections` 或 `tab=statistics` 保留页签；片库的 `page/pageSize` 与合集的 `collectionPage/collectionPageSize` 独立保存，切换页签不相互覆盖。没有参数的旧书签仍按原默认值打开（每页 20 条、DHT 默认已验证），非法参数按有效默认值处理。只保存列表浏览条件；编辑弹窗草稿、账号凭据和 CSRF 不由此机制写入网址。桌面端共用的影视组件只有网页显式启用时才读取、更新网址。

```sh
bun install --frozen-lockfile
bun run admin:dev       # 127.0.0.1:1421/admin/，代理到 127.0.0.1:8787
bun run admin:build     # apps/admin/dist
bun run build:frontend  # 桌面、管理与影视展示前端一起构建
bun run verify
```

直接在仓库根目录启动服务端时，默认读取 `apps/admin/dist`；可通过 `ASSEMBLE_ADMIN_ASSETS_DIR` 指向构建目录。Docker 镜像在 Bun 阶段构建管理端，运行时读取 `/usr/share/assemble/admin`，不需要另外部署站点或改变共享 nginx。

本机查看服务端实际托管的网页时，先执行 `bun run admin:build`，再执行 `bun run server:dev`，浏览器访问 `http://127.0.0.1:8787/admin/`。这与开发热更新用的 1421 地址用途不同；两者都只提供网页。正式使用时仅需浏览器访问已部署服务，不需要在管理员电脑上启动本地服务、安装 Bun 或安装 Assemble 桌面端。

管理端通过原生同源 POST 表单提交退出，并只允许返回固定 `/admin/` 的登录入口。服务端确认撤销会话后才清理浏览器 Cookie；撤销失败时保留会话并提示重试。其他网页账户退出页保留重新登录的网页链接。

管理端与桌面端通过 `@assemble/ui` 引用 `packages/ui`。添加基础组件在该包目录使用 `bunx --bun shadcn@latest add <组件>`，保留既有主题；两个应用不复制独立实现。

## 停用账户

管理端的网页里没有封禁或者删除账户的入口（决策 0006 的范围）。账户出了事，在服务器的命令行上按邮箱处理：

```sh
docker compose exec -T assemble assemble-server suspend-account <邮箱>
docker compose exec -T assemble assemble-server resume-account <邮箱>
```

停用之后这个账户哪里都登不进去：密码或 GitHub 授权对了也不行，网页登录状态当场作废，电脑与助手上的 Assemble 每一次请求都被拒。数据原样留着，恢复之后设备照旧能用，网页要重新登录。两次操作各写一条审计记录；重复停用或者恢复一个没被停用的账户时什么都不做。
