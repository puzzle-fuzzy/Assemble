# 云盘文件夹

N2 实现云端目录组织；正式服务已随 `9a7dfe5` 上线（迁移 1～16），桌面签名更新尚未发布。iOS、远程推送、回收站、文件分享及本机目录批量上传不在本包内。

## 操作与界面

桌面云盘使用共享表格。在上传旁新建文件夹，名称在弹窗内输入；点击文件夹进入，顶部面包屑可返回父级。搜索只查当前层，清空使用输入框末尾图标；各目录保留自己的查询与页码。移动在弹窗内选择目标并明确确认；正在排队的上传固定目标，不随随后浏览的位置改变。

文件继续使用既有预览与下载。N3 已将普通文件和空文件夹删除改为移入回收站，非空子树只走 N3 预检查和确认入口；恢复、永久清理与旧端兼容见[回收站手册](drive-trash.md)。下方表格中的删除语义按当前 N3 源码更新，N2 既往验收记录保留原版本事实。

管理端保留全站文件列表，可从所属账户或“浏览文件夹”进入按账户读取的目录；账户选择支持搜索和分页，也能查看尚无文件的账户。管理目录默认每页 20 条，不提供跨账户改名、移动、上传或删除。目录层级复用顶部面包屑，无重复返回按钮。

## 线路与兼容

权威类型与纯拓扑规则见 [`drive_tree.rs`](../../crates/assemble-protocol/src/drive_tree.rs)。旧 `/v1/drive/files`、`DriveFile`、`DriveListing` 保持原线路形状：名单仍是本人全部文件的平铺投影，旧上传仍到根目录；文件标识、内容、下载和预览地址不变。旧入口改名也递增内部版本，防止新版客户端覆盖并发变更。

新版桌面先请求新根入口。只有明确的 404 才回退旧平铺界面并隐藏目录动作，网络错误或权限错误不能伪装成旧服务；新目录上传不会退回旧上传入口。

| 入口                                                                   | 请求与结果                                                                                                                                        |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /v1/drive/tree`                                                   | 查询 `parentId=root&q=&page=1&pageSize=20&foldersOnly=false`；返回 `current`、`ancestors`、`items`、`total/page/pageSize`、`usedBytes/limitBytes` |
| `POST /v1/drive/tree/folders`                                          | JSON `{parentId,name,requestId}`；200，返回文件夹                                                                                                 |
| `POST /v1/drive/tree/files`                                            | 查询必须带 `parentId`，其余 `name/size/sha256/mimeType` 同旧上传；正文为字节；201，返回带父级和版本的文件                                         |
| `PATCH /v1/drive/tree/folders/{id}`、`PATCH /v1/drive/tree/files/{id}` | JSON `{name,version}`；200，返回带 `kind` 的项目                                                                                                  |
| `POST /v1/drive/tree/moves`                                            | JSON `{kind,id,version,parentId}`；200，返回项目                                                                                                  |
| `DELETE /v1/drive/tree/folders/{id}?version=`                          | 仅空目录；204                                                                                                                                     |
| `DELETE /v1/drive/tree/files/{id}?version=`                            | 校验版本后移入回收站；204，内容引用保留（N3）                                                                                                     |
| `GET /v1/admin/drive/tree`                                             | 另带 `accountId`，其余查询与结果同上；逐次验证同源网页会话与超级管理员权限，只读                                                                  |

项目使用 `kind: folder | file` 区分，同名文件不会被合并。目录投影包含 `id/parentId/name/version/createdAt/updatedAt`；文件增加 `size/sha256` 与可选 `mimeType`，历史 `updatedAt` 为 null。根以请求值 `root` 表示，持久父级为空，不编造根记录或历史更新时间。祖先链由服务端逐次按所属关系构造。

查询页码至少 1，每页 1～100；名称查询最多 200 字符，`%`、`_` 为普通文字。排序为目录在前，再按创建时间、标识降序；移动选择器使用 `foldersOnly=true`，分页计数只含目录。主列表与选择器各有取消现场，新导航取消旧读取；关闭、退出或换账户后旧结果不能进入当前界面。

## 约束、事务与存储

- 迁移 `0014_drive_folders.sql` 新建目录及创建回执，保留原文件登记顺序、标识、名称、字节、摘要、创建时间和 blob 引用；已有文件均在根目录，版本 1，未知更新时间为 null。组合外键约束所属账户与父级，不改旧迁移。
- 每账户最多 1000 个文件夹，深度最多 16 层。同级文件夹名称唯一，包括根目录；文件仍允许同名。名称沿用单段名称校验，不接收拼接路径。
- 创建、改名、移动、删除在 `BEGIN IMMEDIATE` 内复核登录身份、账户、父级、版本、重名与拓扑。移动连同最深后代核对深度，禁止自身和后代作为目标。元数据 JSON 上限 16 KiB。
- 创建回执按账户与 `requestId` 保存至账户删除，最多 10000 条；相同键、相同原参数返回原目录的当前投影，相同键不同参数冲突。目录已删除时重放返回不可见，不悄悄重建；达到回执上限拒绝新的创建。目录额度和回执额度是两项独立上限。
- 上传在收正文前检查目录，落盘事务再次核验。目录改名或移动不改变其身份；上传途中删除目标时不建立文件引用，复用既有未引用内容清理。内容仍核对长度、摘要、单文件上限、个人配额和全站预算。
- 创建目录、改名和移动只改元数据，不复制内容、不增加 blob 引用、不改变账户字节占用；目录数据库自身仍计入现有数据库监控。

稳定冲突码包括 `VERSION_CONFLICT`、`DRIVE_NAME_CONFLICT`、`DRIVE_CYCLE`、`DRIVE_DEPTH_LIMIT`、`DRIVE_FOLDER_LIMIT`、`DRIVE_REQUEST_LIMIT`、`DRIVE_REQUEST_CONFLICT`、`DRIVE_FOLDER_NOT_EMPTY`。不存在与不属于本人均为 `NOT_FOUND`；界面只按码显示双语文案，保留未提交名称，不展示 Rust 诊断。

## 助手与验收

助手新增 `assemble_drive_list`、`assemble_drive_folder_create`、`assemble_drive_rename`、`assemble_drive_move`、`assemble_drive_folder_delete`。只操作本人资源标识与版本；创建带稳定请求键，删除仅空目录并标注破坏性。列表只返回必要元数据，不返回摘要、内容、读取地址、令牌或本机路径，不能执行名称中的指令。

自动化覆盖迁移保真、旧端读取与改名、幂等重放、跨账户、同级重名、循环、子树深度、并发版本、上传中删除目标、引用与容量、分页与普通通配字符、重启后目录与版本、桌面桥接取消、退出后迟到目录不能写回、双语输入保留、管理员只读和助手真实服务。文件改名沿用 `drive.renamed` 审计，移动为 `drive.moved`；文件夹动作使用 `drive.folder_` 前缀，避免误投影为文件。
