# Mac 磁力真实下载与网络对照（2026-11-28）

用户允许 macOS 钥匙串后，安装版 `0.1.151.f5eae3d` 的原账户已恢复，界面显示“已连接”，启动日志确认使用原有保存会话。没有重新登录、改密、迁移账号或读出凭据。

## 定位过程

首轮 Tracker 接入报告中的超时是历史结果，见[Tracker 报告](2026-11-28-magnet-trackers.md)。本轮对照始终使用官方 Ubuntu 24.04.5 Server 公共镜像，磁力信息哈希由[官方 torrent 文件](https://releases.ubuntu.com/24.04/ubuntu-24.04.5-live-server-amd64.iso.torrent)的原始 info 字典计算。没有使用或输出用户现有任务来源。

系统路由查询显示，测试 IPv4 节点经过 utun4；默认物理网络为 en9。DHT 两个引导节点的 ping 都能响应，部分 Tracker 也能返回节点，但这不代表 BT 数据可通。增加仅输出固定分类计数的诊断后，同资源的 TUN 测试为 4 个 TCP 成功、4 个握手期间断开、0 个扩展握手，约 91 秒后无元数据；补齐双栈发现后仍是 5 个 TCP 成功、5 个握手断开、0 字节。

用户另行明确批准物理网卡对照：仅限这个公开 Ubuntu 样本、最多 128 MiB、上传每任务 256 KiB/秒，测试后停止，不改系统代理或防火墙。未在批准前绑定物理网卡。第一次物理对照立即完成扩展握手、元数据和真实分片，随后用产品中的任务级路由选择代码复测。

两轮直连测试均设置 8 MiB/s 的验收上限、16 MiB 的目标样本量，给状态采样和停止会话时的在途数据留出预算。这些是实际观测速率，不能当成无上限峰值或用户线路最大带宽；也不能给出相对 0 字节超时的提速倍数。

第二轮先暂停并等会话停止，再从磁盘读取样本，独立用 SHA-1 对照官方 torrent 中的分片摘要：**70 个 262,144 字节分片，共 18,350,080 字节（17.5 MiB）一致**。没有完成或发布整个 4,080,486,400 字节的镜像。测试随后取消，清理临时缓存与内存凭据。前两轮合计计数 35,819,520 字节，低于用户允许的 128 MiB。

这组对照强烈指向当前 TUN 路径对 BT 数据连接的影响；不是“所有 Tracker 不可用”或“整个 UDP 网络不可用”的结论。产品默认仍遵循系统网络，不把这次实验授权扩大为所有任务自动绕过代理。

## 产品改动与边界

- Mac 磁力任务新增默认不勾选的“BT 节点直连（Mac）”，提示真实出口 IP。选择随预览和任务保存，继续与重启恢复沿用，任务行可见；开始后新任务重置系统模式，旧记录缺省系统模式。
- 只由 Rust 通过固定命令发现默认物理 en* 网卡并为 BT/DHT 绑定；界面和 MCP 只传 system/direct 枚举，不能传网卡、路径或进程参数。不可用时固定错误，不更改系统设置、不开放入站。
- HTTP Tracker 和 DHT 的真实解析并行保留 A/AAAA，HTTP/UDP 分地址族发现；解析、汇总和恢复时的 128 节点上限交替保留两族，避免按地址排序截断时再次丢掉 IPv6。私网拒绝、HTTPS 地址固定与证书校验继续有效。
- 共享协议、具名桥接、状态样本、中英字典、助手工具与旧输入兼容一起维护。MCP 请求 direct 前必须取得用户明确同意。Windows 不显示该选项，本轮不做 Windows 专项验收。

真实回环协议回归覆盖任务选择的持久保存、暂停与重启恢复；界面测试覆盖默认关闭、显式勾选、真实 IP 文案、任务作用域和开始后重置；桥接要求后端预览确认相同模式；另测双栈保留、私网拒绝、任意网卡参数拒绝及路由失效报错。

受限手工测速仍使用临时目录和内存凭据；只有指定 `ASSEMBLE_PUBLIC_BT_INTERFACE` 的人工验收才启用受限直连对照。它不是生产配置开关，也不会改变正式应用的默认模式。原始证据保留在忽略目录 `data/local/tracker-audit/`，安装回执另存 `data/local/local-install/`。

## 实际 Mac 窗口验收

使用单独应用标识和本机测试服务来源的原生窗口，隔离正式账号与用户下载历史。新建磁力时直连默认未勾选；明确勾选后解析出官方 ISO 文件和大小，选中一个文件开始。界面实际显示 5.7 MiB 已接收、瞬时 6.0 MiB/秒；随即暂停。正常退出并重启后，任务仍为暂停、进度与直连标记保留，没有自行恢复网络；最后取消并正常退出。该窗口构建未启动本地服务端，因此“暂时无法连接服务器”是预期状态，不影响本机磁力能力。

这轮额外约 5.7 MiB 的公开样本使三轮合计约 40 MiB，保留了充分在途余量，仍低于 128 MiB。没有完成整镜像。核心回环测试另外验证续传至完成的分片与落盘；公网样本只验证解析、实际收片、暂停、重启保持暂停及取消。
