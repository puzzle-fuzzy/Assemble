# 管理端影视样式同步与正式复测

2026-11-27 用户补充要求管理端同步影视站详情样式，并处理封面加载失败。旧共享图片组件的占位层带有 96px 最小高度，文字、内边距和重试按钮还会继续撑高小图。

## 实现

- 管理片库与合集成员详情保留弹窗、查询和维护入口，改为左封面、右资料，窄屏上下排列。
- 封面原图预览、轮播、键盘、触摸、缩略图与开合动画提取到 `packages/media`，两站共用；公共站继续使用原来的同步图片地址和响应式海报，详情资源仍按需加载。
- 正常、缺图、加载与失败共用固定比例外框。演员头像固定为 48×72；来源搜索、合集选择和图集维护的缩略图同样受外框约束。失败可以重试，预览触发层不会遮挡重试按钮，小图使用图标按钮和无障碍名称。
- 取消旧加载器请求，忽略迟到结果；图集通过既有客户端读取，账户切换、详情卸载与失效会话清理预览。不增加接口、权限或数据库迁移。
