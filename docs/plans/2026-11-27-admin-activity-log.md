# 管理端操作日志

用户要求查看谁在什么时候远程连接、上传文件、更新影视和传输文件，并能点击定位对应业务数据。复用现有管理员、同源边界与共享 shadcn 表格，不增加桌面端入口或远控能力。

## 设计

- 扩展已有追加式 `audit_log`，记录操作人/设备名称与对象的安全元数据快照；历史记录仅展示已有动作、时间及可解析的当前对象，不伪造历史快照。
- 文件上传完成、传输发起及终态、影视条目/合集维护、远控请求/批准/结束进入日志。远控超时、设备撤销、进程重启后的中断也应有明确结束记录；重复请求不能重复记同一次生命周期变化。
- 对象快照仅含名称、标识、归属、大小、设备双方及状态。禁止密码、令牌、会话 Cookie、防伪值、握手材料、验证码、画面、键鼠输入、剪贴板、文件路径、影视私人备注和磁力进入日志。
- 管理端支持类型、关键词和北京时间日期筛选、分页、手动刷新，新增只读远控/传输详情；文件和影视可深链接至既有详情。已删除或过期的数据保留日志，不能错误打开其他对象。
- 管理 API 每次检查已验证超级管理员及同源，设备令牌不可访问；无缓存。使用新迁移 0015，不修改已经提交的迁移；0014 属于其他会话的文件夹功能，保留其改动。
