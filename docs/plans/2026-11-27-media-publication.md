# 影视跨端边界与主动公开

用户确认：管理端维护所有用户影视；桌面只维护本人；全站和个人网页均只读展示已公开内容。采用“默认私有，主动公开”，旧私人记录不自动公开。正式库与 Jarvis 源数据不在本次修改范围。

## 实施范围

1. 保留 shared/private 归属，新增 published、只读 owner 投影与 0012 迁移。既有共享记录和合集保留。
2. 增加独立公开 API；全站与 `/movies/users/{accountId}` 使用同一公开投影，备注始终剔除，磁力要求登录。
3. 扩展同源网页管理 API 读取和维护所有用户记录；目标归属与操作者分离，成功修改与审计同一事务提交，设备凭据不能调用管理 API。
4. 复用现有 shadcn 编辑表单增加显式发布选择，保存才生效；桌面移除共享浏览切换，仅维护本人库。个人页分页与类型筛选不能丢掉 ownerId。
5. 重新核对图片、图集、任务、演员及合集投影；撤销公开立即禁止后续匿名读取。独立公开来源缓存、现有共享资产按原授权保留。

## 验证与发布
