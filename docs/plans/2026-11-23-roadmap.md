## 接下来

按先后排。

### 1. 在 macOS 上真实验收一遍

在你自己的终端里运行 `bun run acceptance`（运行手册第 1 节）。它起好本机的服务端、账户和一台叫"工作电脑"的替身设备，构建并启动桌面应用；要你亲手做的只有三件：在应用里登录、往回发一个文件、从菜单栏退出。其余的（发文件过来、核对落盘的摘要与回执、确认退出后离线）由它自动核对并打印结果，大约 15 分钟。主流程之外的不顺利情况（只读的接收文件夹、取消、重发、云盘空间不够）在运行手册第 3 节，有空再逐条试。

完成标准：`bun run acceptance` 的每一项都是 ✓；运行手册"还没有做过的"一节里，属于 macOS 的那几条都被划掉，或者变成写清楚的缺陷。脚本看不见的几样（通知、拖文件夹的提示、云盘、应用挂在后台十几分钟之后窗口是否正常）要你看一眼。

### 2. 建远程仓库，让持续集成跑起来

你定了公开还是私有之后：建仓库、推送、给仓库设变量 `ASSEMBLE_SERVER_ORIGIN`。第一次运行大概率会在 Windows 那一栏暴露问题——那是服务端、客户端与桌面端第一次在 Windows 上编译和测试，出来什么修什么。

完成标准：两个平台的"验证"都是绿的；手动触发一次"安装包"，两份安装包都能下载下来。

### 3. Windows 真机验收并修到能用

按运行手册末尾的清单走：安装、右键菜单、单实例、开关、拖放、登录与收发、开机启动、退出。

前提是两台设备连得上同一个服务。服务端只接受 HTTPS（明文 HTTP 只许用在回环地址上），所以要么等第 5 步部署好，要么临时给本机的服务端开一条 HTTPS 隧道。

完成标准：清单上的八条都走通。Windows 专用的代码目前只做过类型检查，这一步是它第一次真的运行，预计会有要改的地方。

### 4. 签名与分发

- macOS 的签名与公证；Windows 的安装包与签名。要证书，买不买由你定。
- 自动更新：需要先确认要不要（原来的 Electron 版没有）。

公司的 Windows 电脑能运行没签名的程序（你 2026-11-24 确认过），所以验收阶段不签名也行。签名是为了对外分发时不被系统拦下。

完成标准：一台没装过开发环境的电脑能装上并用第 1 步的全部功能。

### 5. 部署到服务器

要先由你定两件事：域名（DNS 要你本人操作）与方式（Docker Compose 或 systemd）。定下来之前不动服务器。

- 材料已经备好，镜像还没有构建过。可以先在本机构建并试跑一次；这要启动本机的 Docker 守护进程，它可能连带把别的项目的容器也拉起来，所以等你点头。
- 按实际磁盘容量复核云盘配额与保留期。
- 部署之后，两台真实设备之间走一遍收发。

完成标准：两台真实设备（一台 Windows、一台 Mac）对正式地址收发文件成功。

### 6. 日程规划

[方案已经出了](2026-11-24-schedule-planning.md)，等你定十件事。最要紧的两件：第一批的范围（建议是日程、提醒、到点通知），以及 Codex / MCP 这条入口要不要在 Assemble 里保留——jarvis 里建日程主要靠它。定了之后按方案里的步骤做。

### 7. 补齐文件传输的边角

都不大，排在日程之后或者见缝插针：

- 桌面端的拒收：收到文件时可以选择不收（服务端的接口已经在）。
- 云盘改名在桌面端的入口；要不要文件夹需要你定。
- 断点续传：现在中断了从头再来。
- 传输记录跨重启保留。
- 收到的文件的权限：现在是仅本人可读写，要不要改成跟随系统的默认值，需要你定。

## 不在本路线图里

- 局域网直传与大文件分片。你选了服务端中转、单文件 100 MB 以内；要改是另一个决定。
- 迁移 jarvis 的账户与数据。新产品、新数据。
- Windows 11 右键菜单的第一层、访达的右键菜单、网页端、管理端、iOS、小程序。
- 宠物、壁纸。

## 需要你决定的事

1. **什么时候做第 1 步。** 在你的终端里运行 `bun run acceptance`，十几分钟；后面每一步都在等它。
2. **GitHub 仓库公开还是私有**（第 2 步）。定了我就建仓库、推送，让持续集成跑起来。
3. **要不要现在启动 Docker，在本机构建并试跑服务端的镜像**（第 5 步）。
4. **部署的域名与方式**（第 5 步）。
5. **签名证书买不买，要不要自动更新**（第 4 步）。
6. **日程规划的十件事**（第 6 步，清单在方案里）。最要紧的是第一批的范围，和 Codex / MCP 这条路留不留。
7. **云盘要不要文件夹。** 现在是平铺的一层。
8. **收到的文件要不要只有本人可读。** 现在是这样；浏览器下载的文件一般是所有人可读。只有接收位置是共用文件夹时才有差别。
