# 发布入口与个人片库边界

2026-11-27 用户要求增加 iOS、Android、macOS 与 Windows 的产品发布页，并同时推进 A3 传输历史、A4 云盘改名、C1 助手下载。允许多个现有会话共同处理；本次不修改 iOS 客户端和远程推送。

## 已确认的影视边界

用户明确选择“默认私有，主动公开”：

- 桌面端维护本人片库，是个人数据入口。
- 管理端管理全部用户的影视内容，明确标识所属账户并记录管理操作。
- 全站影视页展示既有共享库与用户主动公开的条目；不会自动公开已有私人内容。
- 个人公开网页只显示该用户主动公开的内容。登录后的本人可查看自己的私有片库。
- 私人备注不进入公开投影；磁力仍需登录；图片等关联资产的访问必须由服务端按照条目可见性逐次判断。
- 取消公开后，匿名访问该条目和关联私人资产立即失去授权。

原有共享条目和合集保留。此次调整不迁移账户、认证材料或 Jarvis 数据。
