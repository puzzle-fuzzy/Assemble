# Assemble 视频下载插件隐私说明

更新日期：2026-11-25。适用于 0.1.0 开发版。

插件只为用户主动选择的网页视频创建本机下载任务，不含分析、广告、遥测或远程代码。无需注册或登录插件。

## 处理的数据

点击工具栏图标时，插件读取当前网页地址、标题、视频元素和媒体链接、该页已有的资源记录。用户另行开启“网络捕获”并授予权限后，Chrome 可向扩展提供获授权 HTTP(S) 网站的请求地址、媒体类型和声明长度；扩展只为主动启用的标签页保存受支持的媒体，以发现没有显示在网页元素里的视频，不保存其他标签的请求。插件不读取请求 Cookie、认证请求头、响应正文、表单密码或任意网页脚本文本，也不维护全局浏览历史。

媒体地址可能包含临时访问签名。完整地址只保存在扩展后台的 `chrome.storage.session`，不进入弹窗显示、同步存储、日志或持久下载历史。每页最多一百个来源，总共最多二十四个标签页，并限制来源文字总量。十分钟未更新的记录不再可用于下载，在下次扫描时清扫；关闭标签或跨站导航时清除相应记录，浏览器会话结束时由 Chrome 清除 session 数据。停止捕获后不再加入新资源。

语言与外观选择保存在插件页面的本机存储中；不上传、不同步到账户。移除扩展会清除扩展资料。下载文件与桌面应用历史需在本机另行管理。

## 下载与网络

只有点击某条来源的“下载”后，插件才将该媒体地址、标题、类型和去掉查询参数的来源网页地址交给本机 Assemble 原生连接组件。插件不向云端发送这些资料，也不把 Assemble 账户凭据送进浏览器。

桌面程序直接向用户选择的视频服务请求清单、分片、密钥和媒体，视频服务可看到正常的网络请求与 IP 地址。抖音解析只使用应用临时匿名会话，不读取私人浏览器 Cookie。下载器在系统 DNS 全为代理 Fake-IP 的特定情况下，通过固定 Cloudflare DoH 服务查询目标域名；只发送域名，不发送媒体地址或签名参数。详情见[网络下载说明](../../docs/runbooks/network-downloads.md)。

原生组件与桌面的临时连接凭据仅保存在系统凭据库与 Rust 内存，不返回插件。已发布文件及非敏感展示字段保存在本机下载目录和桌面私有历史中。用户可从桌面管理下载；退出桌面应用会停止未完成任务并清理本实例桥接凭据。

## 数据用途与联系

上述数据只用于发现来源、将所选来源加入本机下载及显示状态；不出售，不用于广告、信用或无关用途。没有运营方收集服务器。源站和 DNS 服务对网络请求的处理适用它们各自的政策。

资料处理方式变化时，此文档随版本更新。隐私问题可通过项目的[问题反馈页](https://github.com/puzzle-fuzzy/Assemble/issues)联系维护者。公开商店版的发布者联系邮箱与正式隐私政策页面需在上架前补齐，当前没有声称已发布商店版。
